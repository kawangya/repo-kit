# repo-kit

这是一个基于静态 HTML 的 GitHub 访问与仓库管理入口集合，仓库中主要包含三类页面：

- `index.html`：GitHub UI 中转站首页
- `gk-glq.html`：GitHub 仓库管理器/桌面端界面
- `gk-gzt.html`：GitHub 移动工作台/移动端界面

项目整体并非以完整应用工程形式组织，而是将多个前端页面与静态资源组合在一起，便于在浏览器中直接打开使用。

## 项目概览

从文件结构和页面内容来看，该项目主要用于：

- GitHub 登录与令牌接入
- 仓库列表管理
- 文件浏览与目录导航
- 分支切换与路径跳转
- 搜索、排序、批量操作等仓库管理功能
- 移动端/桌面端两套界面切换体验

## 使用方式

1. 直接在浏览器中打开 `index.html` 作为总入口。
2. 也可以分别打开 `gk-glq.html` 和 `gk-gzt.html`，访问对应的仓库管理界面。
3. 若需要使用 GitHub 相关功能，需按页面内提示配置访问方式，例如 OAuth 或 Token。
4. 由于这是前端静态资源项目，通常无需安装额外依赖。若运行环境受限制，可直接用本地文件方式打开。
